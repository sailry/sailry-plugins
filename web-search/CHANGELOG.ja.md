# Changes

## 0.1.12

自動検索は、モデルが検索を行わなかった場合を含め、失敗したサービスの次の有効なサービスを試します。

## 0.1.11

上下ボタンで検索サービスを並べ替えられます。自動検索はモデル検索を含む有効なサービスを一覧順に試し、未対応の場合は次へ進みます。

## 0.1.10

- モデル検索で未対応の Copilot アカウントを除外

## 0.1.9

- 最近の検索をキャッシュしサービスの利用枠を表示
- 設定済みモデルサービスを明示的に選択する検索を追加

## 0.1.7

- フォームのラベルと入力欄の間隔を拡大
