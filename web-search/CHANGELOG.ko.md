# Changes

## 0.1.12

자동 검색은 모델이 검색을 수행하지 않은 경우를 포함해 실패한 서비스 다음의 활성 서비스를 시도합니다.

## 0.1.11

위아래 버튼으로 검색 서비스 순서를 변경할 수 있습니다. 자동 검색은 모델 검색을 포함한 활성 서비스 순서를 따르며 미지원 시 다음 서비스를 시도합니다.

## 0.1.10

- 모델 검색에서 지원하지 않는 Copilot 계정 제외

## 0.1.9

- 기간 및 도메인 필터 추가
- 검색 서비스 설정 및 동적 페이지 가져오기 대체 경로 추가
- 최근 검색 캐시 및 서비스 할당량 유형 표시
- 설정된 모델 서비스를 직접 선택하는 검색 추가

## 0.1.7

- 양식 레이블과 컨트롤 사이 간격 확대

## 0.1.4

- 마켓 분류와 아이콘 색상 추가
- 도구 이름 번역 추가
- 스킬 이름 번역 추가
